# Lab 3: Responsive Portfolio Website

## Description
This is a one-page responsive portfolio website built using HTML, CSS, Flexbox, CSS Grid, media queries, and animations. It includes sections for Header, Hero, About, Skills, Projects, Contact, and Footer. The design is mobile-first, with breakpoints at 768px (tablet) and 1024px (desktop) for seamless adaptation.

## Features
- Flexbox for header and hero layouts.
- CSS Grid for skills and projects sections.
- Responsive design with media queries.
- Relative units (rem, em, %, vw, vh) for scalability.
- Hover effects and transitions on links, buttons, and cards.
- Keyframe animation on the hero title.
- Clean typography and color theme.

## How to View
1. Clone the repository.
2. Open `index.html` in a browser.
3. Test responsiveness by resizing the window or using browser dev tools:
   - Mobile: < 768px (stacks hero vertically, single-column grids).
   - Tablet: 768px - 1024px (adjusts flex and grid).
   - Desktop: > 1024px (full layout).
